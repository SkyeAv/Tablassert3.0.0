# Tablassert

## Version 4.2.1

### By Skye Goetz and Gwênlyn Glusman

Tablassert is a versatile tool that creates knowledge assertions from tabular data, enhances knowledge with configurable options, and exports KGX-compliant TSVs.

## Usage

### Via Poetry

**First,** Install Poetry

```bash
python3 -m pip install poetry
```

**Next,** Install Tablassert CLI and dependencies with Poetry

```bash
poetry install
```

**Finally,** Run the Tablassert CLI with Poetry

```bash
poetry run cli --help
```
