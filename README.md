# Tablassert

## Version 6.0.0 (Beta)

### By Skye Lane Goetz, Gwênlyn Glusman, and Jared C. Roach

Tablassert Is A Highly Performant Declarative Knowledge Graph Backend Designed To Extract Knowledge Assertions From Tabular Data While Exporting As NCATS Translator Compliant Knowledge Graph Exchange (KGX) Consistent NDJSON.

## Usage (With Nix)

Develop Nix Shell

```bash
nix develop -L .
```

Use Exposed CLI

```bash
tablassert-cli --help
```
