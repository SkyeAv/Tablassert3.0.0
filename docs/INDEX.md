# Tablassert

## Version 6.0.0 (Beta)

### By Skye Lane Goetz, Gwênlyn Glusman, and Jared C. Roach

Tablassert is a highly performant declarative knowledge graph back end designed to extract millions of knowledge assertions from tabular data while exporting NCATS Translator compliant Knowledge Graph Exchange (KGX) consistent NDJSON.

## Quick start (with nix flakes)

```bash
git clone https://github.com/SkyeAv/Tablassert.git .
nix develop -L .
tabalassert-cli --help
```
