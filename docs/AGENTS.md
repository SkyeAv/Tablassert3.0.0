# MkDocs Documentation Structure

## OVERVIEW

MkDocs-based documentation site using the readthedocs theme. Public-facing documentation for installation, configuration, and usage of Tablassert.

## STRUCTURE

```
docs/
├── index.md                  # Homepage / landing page
├── installation.md           # Nix installation guide
├── cli.md                    # CLI command reference
├── tutorial.md               # Step-by-step tutorial
├── configuration/            # YAML configuration reference
│   ├── graph.md              # Graph-level configuration
│   ├── table.md              # Table-level configuration
│   └── advanced-example.md   # Complex config example
├── api/                      # API documentation (autogenerated/curated)
│   ├── fullmap.md            # Entity resolution API
│   ├── qc.md                 # Quality control API
│   └── utils.md              # Utility functions API
└── examples/                 # Tutorial assets
    ├── tutorial-data.csv     # Sample data for tutorial
    ├── tutorial-graph.yaml   # Sample graph config
    └── tutorial-table.yaml  # Sample table config
```

## MKDOCS CONFIGURATION

### mkdocs.yml

**Purpose**: Site navigation, theme configuration, and build settings

**Theme**: readthedocs
- Features: navigation.instant, navigation.sections
- Customization: logo, favicon

**Navigation Structure**:
```
Home: index.md
Installation: installation.md
Getting Started:
  - CLI Reference: cli.md
  - Tutorial: tutorial.md
Configuration:
  - Graph Config: configuration/graph.md
  - Table Config: configuration/table.md
  - Advanced Example: configuration/advanced-example.md
API Reference:
  - Entity Resolution: api/fullmap.md
  - Quality Control: api/qc.md
  - Utilities: api/utils.md
```

## API DOCUMENTATION

### api/fullmap.md

**Purpose**: Entity resolution API reference

**Content**:
- `version4()` - Main entity resolution function
- Parameters: lf (LazyFrame), term_cols, priority_col
- Return type: LazyFrame
- DuckDB query patterns
- Taxonomic filtering options

**Source**: lib/tablassert/fullmap.py

### api/qc.md

**Purpose**: Quality control API reference

**Content**:
- `fullmap_audit()` - QC audit function
- Three-stage cascade: exact → fuzzy → BERT
- Parameters: terms, entities, thresholds
- RapidFuzz configuration (score >= 0.80)
- BioBERT configuration (cosine sim >= 0.80)
- Caching behavior (diskcache ~100MB LRU)

**Source**: lib/tablassert/qc.py

### api/utils.md

**Purpose**: Utility functions API

**Content**:
- `STORE` - Intermediate storage path (storessert/)
- `DISKCACHE` - Disk cache path (cachessert/)
- `hash_md5()` - MD5 hashing utility
- `uuid_namespace()` - Namespace UUID generation
- Path utilities

**Source**: lib/tablassert/utils.py

## DOCUMENTATION PATTERNS

### Code Blocks
- Use markdown fenced code blocks with language specifiers
- Examples: ```yaml, ```bash, ```python
- Include file paths in comments when referencing configs

### Cross-References
- Use relative paths: `[Link text](../installation.md)`
- Use anchor links for sections: `[Configuration](#configuration)`
- Link to code: See `lib/tablassert/models.py`

### Examples
- Start with minimal working example
- Follow with production-ready example
- Include actual config files in examples/
- Reference example files from tutorial

### Versioning
- Document version-specific behavior
- Note breaking changes in CHANGELOG.md
- Reference current Python/Nix versions

## BUILDING AND DEPLOYMENT

### Local Preview
```bash
nix develop -L . -c mkdocs serve
# Site available at http://127.0.0.1:8000
```

### Build Site
```bash
nix develop -L . -c mkdocs build
# Output in site/ directory
```

### CI/CD Deployment
- `.github/workflows/docs.yml` builds MkDocs
- Deploys to GitHub Pages
- Triggered on push to main branch
- No build failures in current CI

## NOTES

- **Theme**: readthedocs with instant navigation
- **No API autodoc** — API docs are manually curated in api/ directory
- **Tutorial assets** are actual working files, not just code blocks
- **CI**: Only docs.yml exists — builds and deploys MkDocs to GH Pages
- **Version info**: Always reference Python 3.13+ and Nix requirements
